# Drone License static article design template

Phase 1 SEO articles use this static HTML/CSS as the visual baseline.

- Main `/drone-license/` is dynamic and uses `index.html`, `styles.css`, `app.js`.
- Individual SEO articles are static HTML.
- This template is `noindex,nofollow` and is not an SEO landing page.
- Article implementation should copy the structure and replace title, meta, H1/H2/H3, FAQ, internal links, CTA and official sources per the Phase 1 SEO plan.
